# حزمة مستندات المشروع — تطبيق مكتبة البرومبتات والصور (Prompt Gallery)

هذه الحزمة تحتوي على كل ما يحتاجه المطوّر لبدء تنفيذ المشروع. الرجاء قراءة الملفات بهذا الترتيب:

| # | الملف | المحتوى |
|---|---|---|
| 1 | `01-PRD-متطلبات-المنتج.md` | وصف المشكلة، الهدف، قائمة الميزات التفصيلية مع معايير القبول |
| 2 | `02-البنية-التقنية.md` | التقنيات المستخدمة، بنية النظام، آلية عمل تخزين الصور |
| 3 | `03-مخطط-قاعدة-البيانات.md` | الجداول، الأعمدة، العلاقات بينها (Schema كامل) |
| 4 | `04-الشاشات-وتدفق-الاستخدام.md` | قائمة الشاشات، وصف كل شاشة، رحلة المستخدم |
| 5 | `05-قائمة-الحسابات-والإعداد.md` | الحسابات المطلوب إنشاؤها، المتغيرات البيئية، خطوات ما قبل البدء |

## ملاحظة مهمة للمطوّر
جميع الخدمات المستخدمة في هذا المشروع **مجانية بالكامل** ضمن الحدود المتوقعة لاستخدام شخصي (لا يوجد اشتراك مدفوع مطلوب لتشغيل المشروع). أي اقتراح لتغيير خدمة أو تقنية يجب أن يبقى ضمن هذا الشرط، ويُرجى مناقشته مع صاحب المشروع قبل التنفيذ.

## نطاق العمل المطلوب من المطوّر
1. بناء الواجهة الأمامية (Frontend) بحسب الشاشات الموصوفة في الملف رقم 4
2. ربط قاعدة البيانات (Supabase) بحسب المخطط في الملف رقم 3
3. ربط تخزين الصور (Cloudflare R2) بحسب الآلية الموضحة في الملف رقم 2
4. نشر المشروع على استضافة مجانية (Vercel أو Netlify)
5. تسليم رابط المشروع + الكود المصدري كاملاً (على GitHub أو ما يعادله) + توثيق بسيط لطريقة التشغيل محليًا

## للتواصل بخصوص أي غموض
أي نقطة غير واضحة في هذه المستندات يجب توضيحها مع صاحب المشروع **قبل** البدء بالتنفيذ، وليس بعده.
