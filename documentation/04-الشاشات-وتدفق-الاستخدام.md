# الشاشات وتدفق الاستخدام

## قائمة الشاشات الكاملة

### 1. شاشة تسجيل الدخول
- حقلين: بريد إلكتروني، كلمة مرور
- زر "دخول"
- لا حاجة لرابط "إنشاء حساب" — الحساب الوحيد يُنشأ يدويًا من لوحة تحكم Supabase

### 2. الشاشة الرئيسية (المعرض)
**العناصر:**
- شريط علوي: شعار التطبيق، شريط بحث، زر "إضافة إدخال جديد" (بارز)
- شريط جانبي (Sidebar) قابل للطي: فلاتر (المجموعات، الوسوم، النموذج، المفضلة، نطاق التاريخ)
- المحتوى الرئيسي: شبكة صور (Grid)، كل صورة تعرض: الصورة المصغّرة + أيقونة مفضلة إن كانت مفعّلة + أول جزء من البرومبت عند التمرير عليها
- زر/قائمة لتغيير حجم عرض الشبكة

**التفاعل:** الضغط على أي صورة → ينتقل لشاشة تفاصيل الإدخال (رقم 3)

### 3. شاشة تفاصيل الإدخال
يمكن تنفيذها كنافذة منبثقة (Modal) فوق المعرض أو كصفحة منفصلة — القرار يعود للمطوّر حسب الأسهل تقنيًا، لكن يجب أن يكون لكل إدخال رابط مباشر (URL) يمكن مشاركته/حفظه في المفضلة بالمتصفح.

**العناصر:**
- الصورة بالحجم الكامل (يسار أو أعلى، حسب التصميم)
- تبويب أو قسم "البرومبت": البرومبت الإيجابي والسلبي، كل منهما بزر نسخ منفصل 📋
- قسم "التفاصيل": النموذج، Seed، Steps، CFG Scale، Sampler، تاريخ الإنشاء
- قسم "الوسوم والمجموعة"
- قسم "الملاحظات"
- قسم "النسخ المرتبطة": إن وُجد إدخال أصل أو إدخالات فرعية، تظهر كصور مصغّرة صغيرة قابلة للضغط
- أزرار الإجراءات: تعديل ✏️، حذف 🗑️، مفضلة ⭐، "قارن مع نسخة أخرى" (يظهر فقط إن وُجدت نسخ مرتبطة)

### 4. شاشة إضافة/تعديل إدخال
نموذج (Form) يحتوي كل الحقول الموصوفة في PRD (قسم 4.1). يُفضّل أن تكون منطقة رفع الصورة تدعم السحب والإفلات (Drag & Drop).

**سلوك مهم:** أثناء كتابة البرومبت، إن اكتشف التطبيق تشابهًا عاليًا مع برومبت موجود (ميزة 4.5 في PRD)، يظهر تنبيه غير مزعج (مثل شريط صغير أسفل حقل الكتابة) مع رابط للإدخال المشابه واقتراح ربطه كنسخة منه.

### 5. شاشة مقارنة الفروقات النصية (Diff View)
تُفتح عند اختيار "قارن" بين إدخالين مرتبطين. تعرض البرومبتين جنبًا إلى جنب (أو فوق بعض على الجوال) مع تلوين الفروقات:
- 🟢 كلمات مُضافة في النسخة الجديدة
- 🔴 كلمات محذوفة من الأصل

### 6. شاشة المقارنة الجانبية (Compare View)
يختار المستخدم إدخالين أو أكثر (عبر مربعات اختيار Checkbox تظهر في المعرض عند تفعيل "وضع المقارنة")، ثم يضغط "قارن المحدد" لفتح شاشة تعرض الصور والبرومبتات والبيانات الوصفية جنبًا إلى جنب في أعمدة.

### 7. شاشة إدارة المجموعات
قائمة بكل المجموعات مع عدد الإدخالات في كل واحدة، وأزرار إنشاء/تعديل/حذف مجموعة.

### 8. شاشة الإعدادات
- زر "تصدير كل البيانات" (JSON)
- زر "استيراد بيانات" (رفع ملف JSON)
- زر تسجيل الخروج

## رحلة المستخدم النموذجية (User Flow)

```
تسجيل الدخول
   │
   ▼
المعرض الرئيسي (فارغ في البداية)
   │
   ▼
الضغط على "إضافة إدخال جديد"
   │
   ▼
رفع صورة + كتابة البرومبت + (اختياري) ربطه بإدخال سابق
   │
   ▼
الحفظ → يظهر الإدخال في المعرض فورًا
   │
   ▼
(لاحقًا) البحث عن برومبت قديم عبر شريط البحث أو الفلاتر
   │
   ▼
فتح تفاصيل الإدخال → نسخ البرومبت → استخدامه في أداة توليد الصور
   │
   ▼
(عند وجود نسخة معدّلة) مقارنة الفروقات بين النسخة القديمة والجديدة
```
